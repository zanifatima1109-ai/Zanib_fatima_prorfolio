## How to run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.
   - No build step or server required — it's pure HTML/CSS/JS.

## Deploying with GitHub Pages (free)
1. Create a new public repository on GitHub (e.g. `zainab-fatima-portfolio`).
2. Push this folder to the `main` branch.
3. In GitHub, go to **Settings → Pages**.
4. Under "Build and deployment", set **Source** to **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Your site will be live at `https://<your-username>.github.io/zainab-fatima-portfolio/`

## Customizing
- Update the contact email/phone in `index.html` and the footer.
- Replace the example project cards in the Projects section with your real projects.
- Add your own images to `assets/` and reference them in `index.html`.
